# 動くLINEスタンプ制作パイプライン（ちほ用）

グリーンバック動画から、LINE Creators Market 申請用の
アニメーションスタンプ一式を作るための自分用ワークフロー。

## 使うツール

| 役割 | ツール |
|---|---|
| キャラクターシート作成 | 画像生成AI |
| 動画生成 | 動画生成AI（グリーンバック指定できるもの） |
| 変換・選定・申請ファイル作成 | Claude Code + このフォルダの `stamp.py` |

## 初回セットアップ

```bash
pip install pillow numpy imageio-ffmpeg
```

（ffmpeg 本体が入っていればそれが優先で使われる。無ければ imageio-ffmpeg 同梱のものを自動で使う）

## 全体の流れ（6工程）

```
1. キャラクターシート作成      … 画像生成AI（prompts.md のプロンプト）
2. 動きを60個リストアップ      … AIに出させる（prompts.md のプロンプト）
3. グリーンバック動画を生成     … 1動作1.5秒 × 10動作/本 × 6本
4. 動画 → APNG候補に一括変換   … stamp.py convert  ←ここから自動化
5. 確認ページで24個を選定       … stamp.py preview
6. 申請用zipを作成して申請      … stamp.py package
```

### 制作ポリシー（売れた理由なので崩さない）

- **文字を入れない。そのかわり動きを大きくする。**
  文字がなければ海外ユーザーもそのまま使える（売上の約2割は海外）。
- 感情は「文字で説明」ではなく「動きの大きさ」で伝える。
- 動きのアイデア出しの段階では「生成が安定しなさそう」と間引かない。
  崩れたら後工程で不採用にすればいい。60個 → 最終24個まで自然に減る。

---

## 工程1〜3（AI生成パート）

プロンプトは全部 [`prompts.md`](prompts.md) にまとめてある。

1. キャラ画像を渡してキャラクターシートを作る
2. 動きを60個出させる
3. 動画生成AIでグリーンバック動画を作る
   - 固定カメラ・全身・背景は均一なグリーン
   - 1つの動き = 約1.5秒、1本の動画に10動作（15秒）
   - 60動作 = 動画6本

## 工程4：動画 → APNG変換

```bash
cd line-stamp
python stamp.py convert 動画1.mp4 動画2.mp4 ... --every 1.5
```

やってくれること:

- 1.5秒ごとにカットして、それぞれをスタンプ候補APNGに変換
- グリーンバックを自動検出して透過（緑かぶり除去つき）
- **キャラ内部の透過穴を自動修復**（過去のリジェクト原因対策）
- 小さな浮きゴミの除去
- LINE規格に自動適合:
  APNG / 最大320×270（偶数）/ 5〜20フレーム / 再生1〜4秒ぴったり / 300KB以下

主なオプション:

| オプション | 用途 |
|---|---|
| `--segments "0-1.5,1.8-3.4"` | カット位置を手動指定（動きの区切りがズレたとき） |
| `--duration 1` | 再生秒数を固定（省略時はカット長から自動で1〜4秒） |
| `--frames 12` | フレーム数（既定10。動きが速いなら増やす） |
| `--key-low 55 --key-high 130` | 透過の強さ。緑が残る→数値を上げる、キャラが欠ける→下げる |
| `--min-speck 100` | 除去する浮きゴミの最大面積px（既定40） |
| `--start-index 11` | 追加生成時の連番開始（省略時は自動で続きから） |

動画を追加で回すときは同じ `--out` に向けて実行すれば連番が続く。

## 工程5：24個を選定

```bash
python stamp.py preview
open work/candidates/preview.html   # ブラウザで開く
```

- ▶クリックで動きを再生、「選択」ボタンで採用
- **クリックした順番 = 申請時の並び順**（選択中バッジに番号が出る）
- 8/16/24個選ぶと「packageコマンドを表示」でそのまま実行できるコマンドが出る

### 並び順のルール（地味に重要）

1. 1個目はセットの「顔」になるものにする
2. 前半に、使用頻度が高そうなもの（挨拶・OK・ありがとう系）を固める
3. 似た絵柄・似た動きが隣り合わないように散らす

## 工程6：申請用zipを作成

```bash
python stamp.py package --list "cand_03,cand_11,cand_07,..." 
```

`submit/` に以下が生成され、全ファイルの規格チェックが通った場合だけ zip 化される:

- `main.png` … 240×240 APNG（既定では1個目のスタンプから生成。`--main cand_XX` で変更可）
- `tab.png` … 96×74 静止透過PNG
- `01.png`〜`24.png` … 選定したスタンプ（リストの順番どおり）
- `stamps.zip` … 申請用

あとは LINE Creators Market → 新規登録 → アニメーションスタンプ でアップロード。

## 規格チェックだけしたいとき

```bash
python stamp.py validate submit/stamps.zip
python stamp.py validate work/candidates/cand_01.png
```

サイズ・フレーム数・再生時間・容量・**内部透過穴** を全部チェックする。
リジェクトされたら、まずこれを回して原因を特定する。

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| 緑のフチが残る | `--key-high` を150〜180に上げる |
| キャラの一部（緑っぽい服など）が消える | `--key-low` を30〜40に下げる。それでもダメならキャラの緑色は避ける |
| 動きの区切りとカットがズレる | `--segments` で手動指定 |
| 300KB超えの警告 | 自動で減色→縮小→間引きされる。画質が気になるときは `--frames 8` で再生成 |
| 「イラスト内部が透過」でリジェクト | `validate` で該当ファイルを特定 → `convert` をかけ直す（穴修復は自動） |

## LINEアニメーションスタンプ規格（メモ）

- 形式: APNG（拡張子 .png）
- スタンプ画像: 最大 320×270px、偶数サイズ推奨
- フレーム数: 5〜20
- 再生時間: ループ込みで 1/2/3/4 秒ぴったり（ループは1〜4回）
- 容量: 1ファイル 300KB 以下
- 背景透過（キャラ内部の見えない透過穴もリジェクト対象）
- 1セット: 8 / 16 / 24 個
- main.png: 240×240 APNG ／ tab.png: 96×74 静止透過PNG
