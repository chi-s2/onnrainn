# 工程1〜3で使うプロンプト集

## 工程1：キャラクターシート作成（画像生成AI）

キャラ画像を添付して:

```
このキャラクターのキャラクターシートを作ってください。

- 白背景、1枚にまとめる
- 全身の正面・横・背面の3面図
- 表情バリエーション（笑顔・怒り・泣き・驚き・照れ・すまし顔）
- 体型・頭身・輪郭線の太さ・配色が全カットで完全に一致するように
- 文字ラベルは最小限でOK
```

できたシートは以後の動画生成で毎回参照画像として渡す。

## 工程2：動きを60個リストアップ（テキストAI）

```
LINEの動くスタンプにするキャラクターの「動き」を60個リストアップしてください。

条件:
- 文字を入れずに感情・意味が伝わること（海外ユーザーもそのまま使える）
- そのかわり動きは大げさに。全身を使うリアクションを優先
- 日常会話で使用頻度が高いものを多めに:
  挨拶 / OK / NO / ありがとう / ごめん / 了解 / おつかれ / おやすみ /
  笑い / 泣き / 怒り / 驚き / 照れ / 応援 / 待って / 拍手 など
- 「生成AIで安定しなさそう」という理由では間引かない（崩れたら後で不採用にする）
- 1行1動作、体の動きが具体的に分かる書き方で
  （例: 「両手を大きく振って飛び跳ねながら挨拶」）
```

## 工程3：グリーンバック動画生成（動画生成AI）

60動作を10個ずつに分けて、動画6本を生成する。1本あたりのプロンプト:

```
添付のキャラクターシートのキャラクターが、以下の10個の動きを順番に演じる動画。

- 背景: 完全に均一なグリーンバック（クロマキー用、#00B140）
- カメラ: 完全固定、正面、全身が常にフレーム内
- キャラは画面中央、床の影は無しか最小限
- 各動作は約1.5秒、動作間で一瞬基本ポーズに戻る
- 文字・エフェクト文字は一切入れない
- 動きは大げさに、感情がはっきり伝わるように

動き:
1. （動作1）
2. （動作2）
...
10. （動作10）
```

### 動画生成のコツ

- 尺は「1動作 ≒ 1.5秒」が目安。10動作なら15秒
- この構図とカット割りさえ守れれば動画生成AIは何でもいい
- 多少の失敗カットは気にしない。全体の7〜8割使えれば十分
  （60動作 → 最終的に採用するのは24個）
- キャラの服や小物に緑色があるとクロマキーで消えるので、
  キャラクターシートの段階で緑色は避けておく
