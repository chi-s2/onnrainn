# memory（ファンとのやり取りの記録テンプレ）

> 「この子はわたしを覚えている」という感覚が、継続フォローと課金の源泉。
> やり取りが増えたらここに追記し、返信時に読み込む。肥大化したら要約して圧縮する。

## 使い方
- 印象的なやり取り・ファンの属性・約束したことを記録
- 月末に「今月の要点」だけ残して古い詳細は圧縮（Claude Codeに要約させると楽）
