# AIインフルエンサー構築キット

ジャンル：**ライフスタイル / ファッション**
メイン：**TikTok**（→ Instagram / LINE で関係構築 → 収益化）
トーン：**親しみ・等身大**

このフォルダは「顔出し不要のAIインフルエンサー」を一人で運用するための設計図一式です。
ガイド（`../ai-influencer-guide.html`）の第3〜6章を、この方向性に合わせて具体化しました。

## ファイル構成と使う順番

| # | ファイル | 役割 | ガイド該当章 |
|---|---------|------|------------|
| 1 | `01_character-sheet.md` | 顔・外見・スタイルの固定仕様＋画像生成プロンプト | 第3章 |
| 2 | `02_persona.md` | 生い立ち・価値観・口癖（人格の芯） | 第4章 |
| 3 | `03_voice.md` | 文章のリズム・語尾・絵文字ルール | 第4章 |
| 4 | `04_boundaries.md` | 言うこと／言わないこと・NGライン | 第4章 |
| 5 | `05_memory.md` | ファンとのやり取りを積み上げる記録テンプレ | 第4章 |
| 6 | `06_30day-plan.md` | 最初の30日でやることの手順 | 第5〜6章・終章 |
| 7 | `07_content-ideas.md` | TikTok用の投稿ネタ・フック集 | 第5章 |

## 使い方（3ステップ）

1. **`01_character-sheet.md` を埋める** → 顔と世界観を1つに固定する（ここが全ての土台）
2. **`02`〜`04` を自分の言葉に調整** → 画像より先に「人格」を決める（ここで差がつく）
3. **`06_30day-plan.md` の通りに動く** → 毎日投稿・関係構築・導線設計を回す

> 名前・年齢・設定はすべて**仮の提案**です。自分の好みに書き換えてください。
> 「唯一無二のディテールを1つ足す」だけは必ず守ること（顔の一貫性の要）。

## 守るべき前提（重要）

- **実在の人物の顔・名前・肖像を使わない**（参照は"雰囲気"まで。1:1で似せない）
- **AIキャラであることを隠さない設計**にする（各プラットフォームの規約・開示ルールに従う）
- **年齢確認・コンテンツポリシーを厳守**。健全なライフスタイル/ファッション路線で運用する
- **課金リンクをTikTokプロフィールに直貼りしない**（Instagram/LINEを1クッション挟む）
- 記載の収益額は元ガイドの一例であり、成果を保証するものではありません
