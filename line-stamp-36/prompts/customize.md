# カスタマイズ集

生成後に日本語で追加指示を出すだけで直せるものが多い。
YAMLを毎回書き換えるより、まず一言お願いするほうが早い。

## キャラが1人のとき

```bash
python3 scripts/build_prompt.py --characters 1
```

`character_2` の記述と各コマの `char2_pose` を落としたプロンプトが出る。

## セリフをまるごと差し替える

`prompts/panels.yaml` の `text` を書き換えて、もう一度 `build_prompt.py` を実行する。
ビジネス用の36個は `prompts/panels-business.yaml` に用意済み。

```bash
python3 scripts/build_prompt.py --panels prompts/panels-business.yaml
```

用途別に作るなら、推し活・家族グループ・カップル・部活など、
「よく送る一言」を36個書き出すところから始めるとブレない。

## 生成後に投げる追加指示

| やりたいこと | 指示文 |
|---|---|
| 絵柄を変える | 生成したスタンプのスタイルを水彩画風に変えてください。キャラクターのデザインはそのままで、塗りのタッチだけ変更してください。 |
| 背景色を変える | 背景色をパステルイエローに変えてください。 |
| 文字を太く／派手に | 全コマのテキストを、もっと太くてポップなフォントに変えてください。色はビビッドカラーで統一してください。 |
| 特定のコマだけ直す | 3セット目 左中のコマだけ、表情をもっと困った顔にして、他のコマはそのままにしてください。 |
| 誤字を直す | 2セット目 中央上の「ちょっと〜！！」の文字が崩れています。同じ構図のまま文字だけ描き直してください。 |
| キャラを差し替える | 添付の新しいキャラクター画像に置き換えてください。構図・セリフ・レイアウトはそのままにしてください。 |

## 最初から透明背景で出したいとき

`prompts/panels.yaml` の `style.background` を `透明` にする。
ただし生成AIの透過は輪郭が甘くなりやすい。
**白背景で生成 → `make_stamps.py` で抜く** ほうが仕上がりは安定する。

## 文字だけ直したいとき

生成し直すとキャラの顔が変わることがある。
文字の誤字・位置ズレは、画像編集で直したほうが早い場合が多い
（記事では Lovart が紹介されている。Photoshop や Canva でも同じことができる）。
