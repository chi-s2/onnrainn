# LINEスタンプ36個を1プロンプトで作る

記事「LINEスタンプ36個作成の『手間』がバグレベルで消滅」のワークフローを、
そのまま回せる形にしたもの。

やること は3つだけ。

1. キャラ画像を添付して、プロンプトを1回貼る → 3×3のシートが4枚できる
2. シートを36コマに分割する
3. 背景を抜いて、LINE規格のPNG＋ZIPにする

2〜3をChatGPTに頼むと位置ズレや白フチが残ることがあるので、
このリポジトリでは**ローカルのスクリプトで確実に処理する**手順も用意している。

---

## 準備

```bash
pip install -r requirements.txt
```

キャラクター画像を2枚（主役＋相棒）用意する。正面・全身で、背景がシンプルなものがよい。
1人だけで作る場合は1枚でよい。

---

## ステップ1：プロンプトを作る

すぐ使えるものが `prompts/prompt-2char.txt` にある。中身を丸ごとコピーするだけ。

セリフやキャラ数を変えたいときは、`prompts/panels.yaml` を編集して組み立て直す。

```bash
# 2キャラ版（既定）
python3 scripts/build_prompt.py -o prompts/prompt-2char.txt

# 1キャラ版
python3 scripts/build_prompt.py --characters 1 -o prompts/prompt-1char.txt

# ビジネス用セリフ36個
python3 scripts/build_prompt.py --panels prompts/panels-business.yaml
```

---

## ステップ2：ChatGPTで4枚生成する

1. GPT-Image-2 が使える環境でChatGPTを開く
2. キャラ画像を2枚添付する
3. ステップ1のプロンプトを貼って送信

`3列×3行 × 4セット（全36コマ）` が指示に入っているので、3×3のシートが4枚返ってくる。

うまくいかないときは:

- **4枚まとめて出ない** → 「合計4枚の画像を生成して」を強調する。1枚ずつ「1セット目だけ生成して」と分けてもよい
- **キャラの顔が変わる** → キャラクターシート（正面・横・後ろ・表情差分）を先に作って、それを添付する
- **文字が崩れる** → そのコマだけ「同じ構図のまま文字だけ描き直して」と指示する

生成された4枚を `sheets/` に保存する（ファイル名は生成順に並ぶようにする）。

---

## ステップ3：36個に切って、透過してZIPにする

### 方法A：ローカルで処理する（推奨・結果が毎回同じ）

```bash
python3 scripts/make_stamps.py sheets/*.png -o out
```

`out/` に以下ができる。

```
out/
├── transparent/          01.png 〜 36.png ＋ main.png ＋ tab.png（背景透過・申請用）
├── with_bg/              01.png 〜 36.png（背景あり・確認用）
├── stamps_transparent.zip
└── stamps_with_bg.zip
```

スクリプトがやっていること:

- 3×3に分割（コマの間の白帯を見て境界を微調整する）
- 外周からつながっている背景だけを透明化する
  → キャラの目のハイライトや白い服など、**内側の白は残る**
- 輪郭を1px内側に寄せてぼかす（白フチ対策）
- 余白を詰めて 370×320px の中央に配置
- main.png（240×240）と tab.png（96×74）を自動生成
- 1ファイルが1MBを超えたら自動で減色して収める

よく使うオプション:

| オプション | 用途 |
|---|---|
| `--select 1-32` | 申請に使う32個だけ書き出す |
| `--main-index 3` | 3コマ目をメイン画像にする |
| `--tolerance 60` | 背景が薄いグレーなどで抜けきらないとき強める |
| `--feather 0` | フチのぼかしを切る |
| `--equal-split` | 白帯検出をやめて完全に等分割する |
| `--bg 255,255,255` | 背景色を明示する（既定は自動判定） |
| `--grid 2x2` | 3×3以外のシートを処理する |

### 方法B：ChatGPTの中だけで完結させる（記事どおり）

生成が終わったチャットに、続けてこれを送る（`prompts/prompt-2char.txt` の末尾にも入っている）。

```
各画像は3×3のスタンプシートです。全てスタンプ用に切り取り、1コマ1ファイルにして、
合計36個のファイルをZIPファイルとして納品してください。
別パターンとしてプロレベルのLINEスタンプに仕上げるよう、背景を除去したバージョンもZIPで納品してください。

※画像は生成せず、加工作業のみ実行
```

手軽だが、コマの切り位置がズレたり白フチが残ることがある。
届いたZIPを解凍して `make_stamps.py` にかけ直すこともできる。

## ステップ4：申請前チェック

LINE Creators Market の規格。

| 画像 | サイズ | 補足 |
|---|---|---|
| スタンプ | 最大 370×320px | 余白10pxほど残す |
| メイン画像 | 240×240px | 1枚 |
| タブ画像 | 96×74px | 1枚 |

- 形式はPNG、背景は透過、1ファイル1MB以内（スクリプトが自動で満たす）
- 画像サイズは偶数
- **スタンプの個数は 8 / 16 / 24 / 32 / 40 個のいずれか**

最後の1点だけ注意。**36個はそのままでは申請できない。**
記事のプロンプトは36コマだが、LINEが受け付ける個数に入っていない。どちらかにする。

```bash
# 32個に絞る
python3 scripts/make_stamps.py sheets/*.png -o out --select 1-32

# 40個にする場合は panels.yaml にコマを4つ足して、5シート目を生成する
```

`make_stamps.py` は個数が規格外だと最後に警告を出す。

## ファイル構成

```

├── prompts/
│   ├── panels.yaml            36コマ定義（日常会話）
│   ├── panels-business.yaml   36コマ定義（ビジネス）
│   ├── prompt-2char.txt       貼るだけのプロンプト（生成物）
│   └── customize.md           カスタマイズ集
├── scripts/
│   ├── build_prompt.py        YAML → プロンプト
│   └── make_stamps.py         シート → 36個のPNG＋ZIP
└── requirements.txt
```
