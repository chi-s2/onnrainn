# 3Dストーリーチャンネル 設計メモ（His Story 日本版）

参考：His Story（@HisYTStory / 登録573万・1358本・1日3〜5本投稿）

## 1. コンセプト

**3Dアニメ × 日本のスカッと／修羅場ストーリー × お金・制度トラブル特化**

日本には既に「漫画動画（スカッと系・修羅場系）」という巨大市場がある。
なので勝負どころは「未開拓ジャンルの先行者」ではなく、次の2点。

1. **見た目の差分** — 2D漫画動画だらけの中に3Dを置く
2. **中身の差分** — 「お金・制度」に寄せる（後述の堀）

### 唯一の堀（競合が真似できない部分）

8つの価値のうち、競合が絶対に真似できないのは **④経験・実績** だけ。
このチャンネルの場合それは **税務行政7年の実務経験**。

「相続」「贈与」「確定申告」「名義」「給与天引き」といった題材を、
制度の手ざわりが分かっている人間が書くと、他の量産チャンネルと density が変わる。
物語自体は創作でも、**制度の描写が正確**なことが差になる。

## 2. 暫定・価値マップ（このジャンル）

競合タイトル10〜20本を集めたら `youtube-kikaku` のモードAで正式版を作ること。
以下は参考チャンネルのタイトル傾向＋日本の漫画動画ジャンルからの暫定値。

| 順位 | 価値 | このジャンルでの現れ方 |
|---|---|---|
| 1 | ⑤珍しい切り口 | 「加害者の属性 × 被害の種類」の組み合わせで作る。ひらめきではなく掛け算 |
| 2 | ⑧編集・演出 | 固定キャラ／固定BGM／固定オチ位置。シリーズとして認識されること |
| 3 | ③情報量 | 1本で完結し、伏線が全部回収されること。長さではなく「抜けのなさ」 |
| 4 | ⑦親近感 | 主人公が視聴者の代弁者になっているか（「私も同じ目に遭った」） |
| 5 | ④経験・実績 | 制度描写の正確さ。ここが本チャンネルの堀 |
| 6 | ①専門性 | 「お金トラブル専門のスカッと」と一言で言えるか |
| 7 | ⑥わかりやすさ | 制度を説明しすぎない。1本につき専門用語は2つまで |
| 8 | ②トレンド性 | ほぼ効かない。ストック型なので追わない |

**労力を割かない：** ②トレンド性。時事ネタに寄せると資産にならない。

## 3. 量産ラインの条件

参考チャンネルの本質は3Dの巧さではなく **1日3〜5本の回転数**。
1本に3日かける作り方では絶対に勝てない。

| 工程 | 決めておくこと | 目標時間 |
|---|---|---|
| ネタ | 発言小町・知恵袋・X の実話系ポスト → 構成だけ借りて自作 | 5分 |
| 台本 | `script-template.md` の型に流し込むだけ | 15分 |
| 3D映像 | 固定キャラセット（主人公／敵役3種／脇役2種）を先に作り使い回す | 20分 |
| 音声 | 合成音声で統一。声質は最初に決めて変えない | 5分 |
| 字幕 | 焼き込み必須（無音視聴前提） | 10分 |

**着手前のテスト：** 同じ工程で3本続けて作る。2本目が1本目より速くならないなら、その作り方は量産に耐えない。設計をやり直すこと。

## 4. 守ること

- **転載しない。** 参考チャンネルの台本・映像をそのまま翻訳・流用するのは著作権とYouTubeの再利用コンテンツ規約の両方でアウト。真似していいのは**フォーマットだけ**
- **フィクション表記を入れる。** 概要欄と動画内に「この物語はフィクションです」を固定で入れる。実話風で押し切ると信頼と収益の両方を失う
- **制度描写はファクトチェック必須。** 相続・贈与・税・労務に触れる回は、公開前に必ず一次情報（国税庁・厚労省など）で裏を取る。ここを間違えると堀がそのまま弱点になる
- **実在の人物・企業・地名を出さない。**
