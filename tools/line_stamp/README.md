# 動くLINEスタンプ制作ツール

工程4（動画 → APNG変換）を自動化するツール一式。

| ファイル | 役割 |
| --- | --- |
| `video_to_stamps.py` | 動画1本 → スタンプ候補のAPNGをまとめて書き出す（工程4のフル自動化） |
| `last_frame_first.py` | 素材1つ → APNG 1個。決めポーズの1コマ目移動と規格合わせ |
| `chroma.py` | グリーンバック除去と、内部の透過穴の始末（上の2つが内部で使う） |
| `sample_cat.py` | 動作確認用の猫グリーンバック動画を作る（生成動画が手元にないとき用） |

```bash
pip install -r tools/line_stamp/requirements.txt
```

## video_to_stamps.py — 動画1本からスタンプ候補を量産

グリーンバックで撮った生成動画を渡すと、カットに分けて全部APNGにする。
1本15秒・1.5秒刻みなら候補が10個できる。

```bash
python3 tools/line_stamp/video_to_stamps.py movie.mp4 -o cand/
```

```
入力      movie.mp4  →  180コマ (12.0fps, 15.0秒)
カット    10個  [1.5秒ごと]
透過      グリーンバック除去 keep=25 cut=60
  OK  01.png  コマ18→18  258x270  1.50秒x2=3秒  198KB  穴12  [無加工（フルカラー）]
  ...
書き出し  cand/  に 10個
内部の透過穴を 156箇所 埋めました（審査対策）
```

### やっていること

1. フレームを取り出す（ffmpeg）
2. カットに分ける（既定1.5秒ごと／`--cuts N`で等分／`--detect`で自動検出）
3. 緑背景を透過（緑かぶりの抑制つき）
4. **キャラ内部に残った透過の穴を埋める** — 「イラストの内部が透過されています」でリジェクトされた原因への対策
5. 中身に合わせて余白を切る
6. 決めポーズ（最終コマ）を1コマ目へ
7. LINE規格に整えてAPNGで書き出す

穴埋めは縮小のあとにもう一度かけている。縮小すると補間で穴と半透明が復活するため。

### 300KBに収める順番

`無加工 → 減色 → コマ間引き → 縮小` の順に落として、最初に収まったところで止める。
スタンプは動きの滑らかさより絵の粗さのほうが目立つので、縮小より先にコマを減らす。
どの手を使ったかは実行ログの `[...]` に出る。

### 手元に生成動画がないとき

```bash
python3 tools/line_stamp/sample_cat.py -o cat.mp4      # 猫の15秒グリーンバック動画
python3 tools/line_stamp/video_to_stamps.py cat.mp4 -o cand/
```

10個の動き（手をふる／おじぎ／ジャンプ／首かしげ／ねる／びっくり／はくしゅ／
うなずく／のび／てれる）を1.5秒ずつ、決めポーズを各カットの最終コマに置いた素材が出る。

### よく使うオプション

| オプション | 意味 |
| --- | --- |
| `--cut-seconds 1.5` | 1カットの長さ（既定1.5秒） |
| `--cuts N` | カット数を指定して等分割 |
| `--detect` | コマ間の差からカットを自動検出（`--sensitivity` で細かさ調整） |
| `--fps 12` | 切り出すfps（既定12）。300KBに収まらないときは下げる |
| `--no-green` | すでに透過済みの素材のとき |
| `--green-keep 25` / `--green-cut 60` | 緑と判定する強さ。抜けすぎ／残りすぎのとき調整 |
| `--max-hole 0` | 大きい穴も含めて全部埋める（既定は面積2%まで） |
| `--start 11` | 連番の開始番号。2本目以降の動画を続き番号で出すとき |
| `--verbose` | 1カットずつ規格チェックを表示 |

### 2本目以降を続き番号で出す

```bash
python3 tools/line_stamp/video_to_stamps.py movie1.mp4 -o cand/ --start 1
python3 tools/line_stamp/video_to_stamps.py movie2.mp4 -o cand/ --start 11
```

### 緑が残る／抜けすぎるとき

- キャラの一部まで消える → `--green-cut` を上げる（例 `--green-cut 80`）
- 背景の緑が残る → `--green-cut` を下げる（例 `--green-cut 45`）
- 輪郭が緑っぽい → 既定で抑制済み。それでも気になれば素材側のグリーンを薄くする

## last_frame_first.py — 素材1つをAPNGに

## 使い方

```bash
# GIF から
python3 tools/line_stamp/last_frame_first.py input.gif -o stamp01.png

# 連番PNGのフォルダから
python3 tools/line_stamp/last_frame_first.py frames/ --fps 12 -o stamp01.png

# 動画から（ffmpeg が必要。透過は付かないので注意）
python3 tools/line_stamp/last_frame_first.py movie.mp4 --fps 10 -o stamp01.png

# 書き出し済みファイルの規格チェックだけ
python3 tools/line_stamp/last_frame_first.py stamp01.png --check
```

出力は APNG（拡張子は `.png`）。LINE Creators Market にそのまま出せる形。

## やっていること

1. 決めポーズのコマを先頭へ移動（既定は最終コマ）
2. コマ数を 5〜20 に調整（多ければ等間隔で間引き、少なければコマを分割。総再生時間は維持）
3. 再生時間を「ループ込みで1/2/3/4秒ぴったり」に調整（1ループの長さ × ループ回数）
4. 320×270 以内・幅高さとも偶数にリサイズ（拡大はしない）
5. 300KB を超えていたら 減色 → 縮小 の順に落として収める
6. 最後に規格チェックを表示

## よく使うオプション

| オプション | 意味 |
| --- | --- |
| `--mode rotate` | 既定。順序を回して決めポーズを先頭へ。コマ数は変わらない |
| `--mode duplicate` | 決めポーズの複製を先頭に足す。コマ数 +1。動きの頭を削りたくないとき |
| `--mode none` | 並べ替えず、整形と書き出しだけ |
| `--pose-frame N` | 決めポーズのコマ番号（1始まり、負数で末尾から）。既定は `-1` = 最終コマ |
| `--fps N` | 連番PNG・動画のfps。アニメ画像に指定すると表示時間を上書き |
| `--loop N` | ループ回数 1〜4。未指定なら元素材の速さに近い組み合わせを自動選択 |
| `--seconds N` | ループ込みの再生時間（秒）1〜4。未指定なら自動選択 |
| `--size WxH` | 収める最大サイズ（既定 `320x270`。メイン画像なら `240x240`） |
| `--clean` | 仕上げに内部の透過穴を埋め、内側の半透明をベタにする |
| `--keep-size` / `--keep-timing` | リサイズ / コマ数・時間調整をスキップ |
| `--max-bytes N` | 上限バイト数（既定 307200 = 300KB） |

### 再生時間の決まり方

LINEは「1ループの長さ × ループ回数」が **1/2/3/4秒ぴったり** であることを求める。
`--loop` も `--seconds` も指定しなければ、元素材の速さ（1ループの長さ）にいちばん近い
組み合わせを自動で選ぶ。速さを変えたくないときはそのままでOK。

```bash
# 1秒の動きを4回くり返す（＝ループ込み4秒）
python3 tools/line_stamp/last_frame_first.py input.gif --seconds 4 --loop 4 -o stamp01.png

# 3秒の動きを1回だけ見せる
python3 tools/line_stamp/last_frame_first.py input.gif --seconds 3 --loop 1 -o stamp01.png
```

### rotate と duplicate の使い分け

- **rotate**：ループ再生される動きなら、開始位置が変わるだけで見た目は変わらない。基本はこちら。
- **duplicate**：「歩く → 座る」のような一方向の動きで、動きの頭から見せたいとき。
  ただし決めポーズが冒頭と末尾で二度出るので、少し間が伸びて見える。

## LINE アニメーションスタンプの規格（ツールが合わせにいく値）

| 項目 | 条件 |
| --- | --- |
| 形式 | APNG（背景透過） |
| スタンプ画像 | 320×270px 以内、幅・高さとも偶数 |
| コマ数 | 5〜20コマ |
| 再生時間 | ループ込みで 1/2/3/4秒ぴったり（1ループの長さ × ループ回数） |
| ファイルサイズ | 1個あたり 300KB 以内 |
| ループ回数 | 1〜4回 |
| 1セットの個数 | 8 / 16 / 24個 |

メイン画像（240×240）とトークルームタブ画像（96×74）は別途必要。
メイン画像も動かす場合は、同じく決めポーズを1コマ目にしておくと揃う。

```bash
# メイン画像（240×240以内）も同じ考え方で
python3 tools/line_stamp/last_frame_first.py input.gif -o main.png --size 240x240
```

※ 規格はLINE側で更新されることがあるので、申請前に公式のガイドラインで最新の数値を確認してください。
