第2章

お金はどこから生まれるのか — 収益の5つの柱

収益構造はシンプルで、柱は5つ。「どの順番で、どう組み合わせるか」が収入の天井を決めます。

1サブスクリプション

メインの安定収入。月額1,500〜4,400円。有料購読者が500〜1,000人いれば手取り月60万〜180万円。ビジネスの心臓部で、他の施策はすべてここに流し込む。

2カスタムコンテンツ

写真セット3,000〜7,500円、短尺動画7,500〜22,500円。単価は小さいが、熱量の高い時期には短期間で数百万円が動くことも。

3ブランド案件

中堅で1投稿7.5万〜45万円、上位で15万〜75万円超。ブランド側もAIペルソナ起用に慣れてきている。

4アフィリエイト＋デジタル商品

リンク、プロンプト集、キャラクターシート、プリセット。自分の構築ノウハウそのものが商品になる。

5有料メッセージ・ボイスノート

ファンとの1対1の接点を課金化。人格設計が機能していれば半自動で回る。

重要なのは、これらは排他ではないこと。月75万円超の運用者は例外なく複数の柱を同時に立てています。

第3章

キャラクター設計 — 「顔」は資産である

キャラクターシートを最初に作る

最初にやるべきはキャラクターシートの作成です。顔・体型・スタイルを完全に固定する設計図で、ここを曖昧にしたまま量産を始めると必ず破綻します。

コツはひとつ。顔をゼロから生成しないこと。実在の参照を2つブレンドし、そこに「唯一無二のディテール」を1つ加える。ほくろの位置、髪の分け目、瞳の色のわずかな偏り——そういう小さな固有性が、再現性と認知度の両方を担保します。

顔の一貫性は技術的なこだわりではなく、
「信頼」という資産そのものである

失敗原因の上位に必ずあるのが「投稿ごとに顔が変わる（face drift）」問題です。フォロワーは無意識に「いつもの顔」を探しています。顔が漂流するキャラクターには、誰も感情を預けません。

第4章

人格設計 — 画像ではなく「人間性」が稼がせる

ここが最も重要な章です。はっきり言います。稼ぐアカウントと稼げないアカウントの差は、画像の美しさではなく人格の有無です。

4つのテキストファイルがキャラクターを生かす

  • persona — 生い立ち、職業、価値観、口癖
  • voice — 文章のリズム、語尾、絵文字の使い方
  • boundaries — 何を言い、何を言わないか
  • memory — ファンとの過去のやり取りの蓄積

言語モデルは返信のたびにこれらを読み込みます。だからこそ数百の会話を同時に回してもキャラクターが一度もブレない。ファンは「この子は私を覚えている」と感じ、その感覚が月額課金とカスタム注文の源泉になります。

Claude CodeとCodexが運用の中核になる

人格ファイルの管理は規模が大きくなるほど複雑になります。Claude Code を使えば、人格ファイルのバージョン管理、memoryの要約・圧縮、返信トーンの自動検証といった人格運用のワークフロー自体を自動化できます。Codex には投稿スケジュールのスクリプト、メタデータのクリーニング、複数プラットフォームへの投稿自動化といった運用レイヤーを担わせます。Claude Codeが「人格の守り手」、Codexが「運用の手足」。この2つを中核に据えると、一人運用でもチーム並みの品質とスループットが実現します。

第5章

コンテンツ量産パイプライン — MiniMax H3を中核に

3層の制作パイプライン

🖼 画像

Flux・GPT Image・Ideogramで、キャラクターシートに厳密に従って量産。「1枚の完璧な写真」ではなく「100枚の一貫した写真」を目指す。

🎬 動画（MiniMax H3）

2K出力に対応し、モーションの自然さでもトップクラス。image-to-video運用なら顔の一貫性も維持しやすい。TikTokでの認知獲得において動画の破壊力は静止画の比ではない。

🔊 音声

ElevenLabsで声を固定。ボイスノート課金（柱5）はここから生まれる。

「AI痕」を消す最終工程

生成後のコンテンツは、あえて意図的に「汚す」。グレインを乗せ、明るさを微妙に崩し、スマートフォンから投稿する。完璧すぎる画像は逆に不自然で、プラットフォームの検知にも引っかかりやすい。メタデータのクリーニングを怠れば、BANリスクが跳ね上がります。この最後の仕上げを雑に扱うアカウントは、素材が良くても生き残れません。

第6章

導線設計（ファネル） — 認知から収益までの一本道

どんなに良いコンテンツも、導線なしには1円にもなりません。ファネルは3層で設計します。

1TikTok ＝ リーチ

アルゴリズムの爆発力で新規層に届ける（認知獲得）。

2Instagram＋Telegram ＝ 関係構築

日常投稿とクローズドな空間で愛着を育てる（ウォーミングアップ）。

3サブスク ＝ 収益化

すべての流れの終着点（マネタイズ）。

TikTokのプロフィールに
課金リンクを直接貼らないこと

この一点だけでアカウント制限のリスクが大幅に下がります。課金導線はInstagramやTelegramを経由させる「ワンクッション設計」が、長く稼ぎ続けるための基本です。第4章で作った人格は、このファネルの中間層でこそ真価を発揮します。

第7章

なぜ多くの人は稼げないのか — 6つの失敗パターン

  1. 美しいだけの「空っぽの人形」を作る — 人格なきキャラクターにファンは定着しない
  2. 売り始めるのが早すぎる — 関係構築前の販売は信頼を破壊する
  3. 投稿ごとに顔が変わる — face driftはキャラクターの死
  4. メタデータをクリーンにしない — 検知とBANのリスクが常につきまとう
  5. 初週から過激なコンテンツを投稿する — プラットフォーム制限まっしぐら
  6. 愛着を育てず即クロージング — ファネルの中間層を飛ばす愚策

失敗の本質はすべて同じです。「技術」を急いで「関係」を飛ばすこと。AIインフルエンサービジネスは、実はとても人間くさいビジネスなのです。
