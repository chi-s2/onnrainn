# 動くLINEスタンプ「ねこちゃん」

猫キャラの**動くLINEスタンプ（APNG）を8個**、コードから書き出すツールです。
LINE Creators Market のアニメーションスタンプ規定に合わせて出力し、
書き出しのたびに規定を満たしているか自動チェックします。

```
python3 generate.py            # out/ に全部書き出す
python3 generate.py --sheet    # 確認用のコマ送りシートも作る
```

必要なのは Python 3 と Pillow だけです。

```
pip3 install Pillow
```

## 出力されるもの

| ファイル | 内容 | 形式 |
|---|---|---|
| `out/01.png` 〜 `08.png` | スタンプ本体 8個 | APNG 320×270 |
| `out/main.png` | メイン画像 | APNG 240×240 |
| `out/tab.png` | トークルームタブ画像 | PNG 96×74（静止画） |
| `out/line-sticker-cat.zip` | 上記10個をまとめたもの | ZIP（そのまま申請に使える） |

## LINE の規定（このツールが守っているもの）

| 項目 | 規定 | このツールの設定 |
|---|---|---|
| 形式 | APNG（拡張子は `.png`）／カラーは RGB | APNG |
| スタンプ画像サイズ | 最大 320×270px。幅か高さの一方は 270px 以上 | 320×270 |
| 個数 | 8・16・24 個のいずれか | 8個 |
| フレーム数 | 5〜20 | 12 |
| 再生時間 | 1・2・3・4 秒のいずれか | 2秒 |
| ループ回数 | 1〜4回。**再生時間 × ループ回数 が 4秒以内** | 2回（2秒×2＝4秒） |
| 1ファイルの容量 | 300KB 以下 | 200〜270KB |
| メイン画像 | APNG 240×240px | 240×240 |
| タブ画像 | PNG 96×74px（静止画） | 96×74 |
| ZIP | 20MB 以下 | 約2MB |

**いちばん引っかかりやすいのが「再生時間 × ループ回数 ≦ 4秒」です。**
2秒のアニメを4ループにすると合計8秒になって弾かれます。
`generate.py` はここを含めて全項目を書き出し時に検査し、外れていれば `NG` を出して終了コード 1 で止まります。

## 申請の流れ

1. `python3 generate.py` を実行して `out/line-sticker-cat.zip` を作る
2. [LINE Creators Market](https://creator.line.me/) にログイン
3. 「新規登録」→ スタンプ種別で **アニメーションスタンプ** を選ぶ
4. スタンプ詳細（タイトル・説明文・販売エリアなど）を入力
5. スタンプ画像のところで ZIP をアップロード
6. 販売価格を設定してリクエスト（審査は数日〜）

## 中身の作り

ファイルは3つだけです。

- **`stickerkit.py`** — 描画エンジン。猫を「パーツの集まり」として組み立てて描く。
- **`scenes.py`** — スタンプ8種類の中身。`frame(t)` が再生位置 `t`（0.0〜1.0）から1コマ返す。
- **`generate.py`** — 全部書き出して規定をチェックし、ZIP にまとめる。

### 猫のポーズを変える

`pose()` に渡す値を変えるだけで表情と姿勢が変わります。

```python
import stickerkit as k

img = k.new_frame()
k.draw_cat(img, k.pose(
    y=246,                    # 足元の位置
    bob=-6,                   # 上下の弾み
    squash=0.9,               # しゃがみ具合（1.0 が標準）
    tilt=-8,                  # 首の傾き（度）
    ear=10,                   # 耳の角度
    paw_r=(60, -120),         # 右手の位置。上げると手を振る形になる
    eyes="happy",             # open / blink / happy / sleepy / sparkle / wide / sad
    mouth="smile",            # x / omega / smile / open / wave / flat
    tail=8,                   # しっぽの振り
))
k.text(img, "おはよう", 160, 30, 34)
k.finish(img).save("test.png")
```

手は角度ではなく**手先の座標**で指定します（肩から手先までを自動でつなぐ）。
「ここに手を置きたい」と思った位置をそのまま書けます。

### 輪郭線の出しかた

パーツを重ねると内側にも線が出てしまうので、
**先に全パーツを太い線で輪郭色に描き、そのあと同じ形を本体色で塗り直す**
という2段階にしています（`stickerkit.draw_group`）。こうすると外周だけに線が残ります。
体と手足はグループを分けてあるので、手足は体の上でちゃんと形として見えます。

### スタンプを増やす

`scenes.py` に `frame(t)` を1つ足して `SCENES` に登録するだけです。
`t=0` と `t=1` がつながるように作るとループが滑らかになります。

```python
def yatta(t):
    img = new_frame()
    jump = abs(_osc(t, 2)) * 20
    draw_cat(img, pose(y=GROUND - jump, eyes="sparkle", mouth="open",
                       paw_l=(-52, -110), paw_r=(52, -110)))
    text(img, "やったー", 160, TEXT_Y, 34, fill=(238, 138, 92, 255))
    return finish(img)

SCENES.append(("09", "やったー", yatta))
```

LINE は 8・16・24個のいずれかなので、増やすなら**16個まで一気に**増やしてください。

### ファイルが 300KB を超えたら

`generate.py` が自動で色数を落として収めます（96色→72→56→…→16色）。
それでも収まらないときは `--frames 10` でフレームを減らすか、
`scenes.py` 側で動く範囲を狭くすると軽くなります。

書き出し後、APNG を読み直して**全フレームが元の絵と一致するか**まで検査しているので、
差分圧縮で絵が壊れていれば `NG` として出ます。

## フォントについて

セリフには IPAゴシック（`/usr/share/fonts/truetype/fonts-japanese-gothic.ttf`）を使っています。
もっとスタンプらしい丸ゴシックにしたい場合は `stickerkit.FONT_PATH` を差し替えてください。
**販売する場合は、使うフォントが商用利用・画像への埋め込みを許可しているかを必ず確認してください。**

## 絵柄について

猫のイラストはすべてこのコードで描いた新規のものです。外部の画像素材は使っていません。
LINEスタンプは既存キャラや他人のイラストの流用が審査で弾かれるため、
色や形を変えるときも「参考にする」までにとどめてください。
